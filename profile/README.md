# CSE 240 — Introduction to Programming Languages

This organization hosts repositories that support the teaching and learning of
**CSE 240: Introduction to Programming Languages** at Arizona State University.

It provides examples, reference implementations, and course materials that help
students explore programming language concepts and paradigms through practical
programming exercises.

## About the Repositories

The repositories include programming examples and supporting materials covering
different programming languages and programming paradigms, including
object-oriented, functional, and logic programming.

These projects are intended to support experimentation, demonstration, and
**learning by doing**.

## Academic Integrity

Course examples are provided for educational purposes. Students should use them
to understand concepts and programming techniques and should follow the academic
integrity requirements of their course when completing assignments.
